# UI 设计与验证

当前界面采用接近 shadcn 的浅色中性设计，覆盖登录/注册、用户聊天、客服工作台、用户管理、商品库、知识库和检索诊断。沿用 Vue 3 静态前端及现有 HTTP/SSE/WebSocket 接口和角色规则。

## 聊天空间与面板调整（2026-11-15）

1. **用户体验**：删除用户端、客服端常驻的发送快捷键说明。输入区默认一行，发送按钮与输入同行，按草稿内容自动增高，上限为 `min(144px, 20dvh)`，超过后在输入框内滚动。保留 Enter 发送、Shift+Enter 换行和输入法保护。压缩工作台标题、会话头及外边距；正文内的 Markdown 图片等比显示，上限为 `min(240px, 32dvh)`，避免单张图片占满聊天区域。
2. **开发体验**：沿用静态 Vue 3，不增加依赖。两个面板复用 `UiResizeHandle`，两个输入框复用 `v-autosize`；宽度边界集中在 `PANEL_SIZES`，布局偏好单独存储为 `supermew.layout.v1`。拖动结束或键盘操作后才写入存储；无效设置安全回退。尺寸观察器和视口事件均在卸载时清理，业务方法与协议保持原实现。
3. **AI Agent 使用体验**：两个分隔控件具有稳定的可访问名称“调整导航栏宽度”和“调整会话列表宽度”，提供 `separator` 角色、关联面板、当前值和上下限。支持左右键每次 8px、Shift+左右键每次 32px、Home/End 到边界、双击恢复默认值；折叠按钮提供 `aria-expanded` 和 `aria-controls`。折叠不清空草稿或选中会话，恢复会话列表时聚焦筛选。

桌面导航默认 208px，可在 176–320px 间调整，收起后 64px。会话列表默认 272px，可在 224–440px 间调整；其实际最大宽度还受可用空间限制，为聊天保留至少 360px，紧凑导航下保留至少 320px。变窄时暂时约束实际宽度，重新放大后恢复用户保存的尺寸。

小于 960px 时导航自动变为图标栏；小于 680px 时采用顶部导航与会话列表/详情分屏，停用拖动控件。桌面折叠状态不会阻止手机返回会话列表。CSS 使用连续的范围媒体查询，JavaScript 保留视口小数，避免浏览器缩放后落入断点缝隙。

同一浏览器、同一真实会话、约 1036×703 CSS 像素窗口的实测对比：输入区约 **153 → 74px**，消息可视区约 **341 → 472px**，增加约 **39%**。该数据仅对应这个窗口与空草稿状态。

- 本轮对桌面客服端、手机客服端与手机用户端执行 axe WCAG 2 A/AA、WCAG 2.1 AA 扫描，均未报告违规。分隔控件的实际键盘、拖动和持久化另行验证；扫描结果不等同于完整 Agent 使用体验验收。

## 三项验收目标

1. **用户体验**：白色工作区、浅灰导航、黑色主按钮、细边框和小圆角；去掉深色导航、绿色底色、登录插画、重复品牌副标题和装饰性配色。桌面列表与编辑区并列，手机依次排列；手机会话队列与详情分屏切换。保留必要的会话状态、文件格式和操作反馈。
2. **开发体验**：不引入新的框架、UI 依赖或构建流程。`style.css` 按 `tokens → base → layout → components → responsive` 定义级联顺序，颜色、圆角、焦点样式集中为变量，复用公共按钮、字段和面板。商品列表使用统一边框和行分隔，删除已废弃的插画样式。图标与品牌 SVG 均保存在仓库。
3. **AI Agent 使用体验**：保留稳定的表单 `id`、`name` 和关联 `label`，导航名称与 `aria-current`，带对象名称的编辑/删除按钮，原生表格和可展开的检索诊断。动态反馈使用 `role="status"` / `role="alert"`，编辑与返回队列有明确焦点。

## 页面和维护约定

| 页面 | 主要结构 | 保留的业务方法 |
| --- | --- | --- |
| 登录/注册 | 居中单列表单 | `handleAuthSubmit` |
| 用户聊天 | 独立滚动的消息区 + 底部输入区，历史独立显示 | `sendUserMessage`、`requestHuman`、`openUserSession`、`closeUserSession` |
| 客服工作台 | 状态筛选/会话队列 + 会话详情 | `openConversation`、`takeoverConversation`、`sendAdminReply`、`closeConversation`、`deleteConversation` |
| 用户管理 | 原生表格 + 新增/编辑表单 | `loadUsers`、`saveUser`、`deleteUser` |
| 商品库 | 商品列表 + 新增/编辑表单 | `loadProducts`、`saveProduct`、`deleteProduct` |
| 知识库 | 文档列表 + 文件上传 + 可展开诊断 | `refreshKnowledge`、`uploadDocument`、`deleteDocument`、`runRagDiagnostic` |

- Vue 挂载点 `#app` 只负责挂载，动态布局类保留在子容器。
- 修改公共变量或现有组件规则，不在文件末尾追加重复覆盖。
- 使用 `minmax(0, 1fr)` / `min-inline-size: 0` 约束长内容，表格、代码和消息在各自区域滚动，不裁切整页掩盖溢出。
- 隐藏标签的定位范围限定在所属控件内。检索诊断展开后，隐藏标签不应撑开整页滚动范围。
- 手机导航保留文字，触屏扩大点击区域，尊重减少动画和强制颜色设置。
- 输入法组合状态下 Enter 不发送；普通 Enter 发送，Shift+Enter 换行。编辑后聚焦字段，返回队列后聚焦筛选。
- Markdown 继续使用现有 DOMPurify / fallback 清洗。未改变鉴权、数据存储、消息同步或模型调用协议。
- 自动化优先使用角色与可访问名称，例如 `getByRole('button', { name: '发送回复', exact: true })`。异步筛选和搜索应等待请求完成及列表更新，再检查数量。

## 上一轮验证边界

本轮真实环境以读取和检索为主，未向原有会话发送新消息，未新增、删除或修改账号、商品和文档。新增/编辑/删除、上传、双端收发、接管和结束会话在上一轮隔离 SQLite/替身模型环境中验证过，不能据此认定真实环境的所有写入与模型生成链路均已通过。

本地运行不等同于生产上线验收；真实新增消息的模型生成、生产部署、压力、真实移动设备及 Safari/Firefox 未在本轮验证。当前 Vue CDN 仍使用项目原有开发构建，生产发布配置需单独验收。
